# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and keep discussions
on-topic. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainer via the contact on the
[GitHub profile](https://github.com/mattheuserb). Reports are handled confidentially.
