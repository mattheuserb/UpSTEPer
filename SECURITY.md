# Security policy

## Supported versions

UpSTEPer is pre-release; only the latest `main` receives fixes.

## Reporting a vulnerability

UpSTEPer parses untrusted CAD files through native code, so crashes or memory corruption caused
by crafted STEP files are security relevant.

Please **do not open a public issue**. Use GitHub's
[private vulnerability reporting](https://github.com/mattheuserb/UpSTEPer/security/advisories/new)
and include a minimal reproducing file if possible. You will get a response within 14 days.

Vulnerabilities in Open CASCADE itself should also be reported upstream to Open Cascade SAS.
