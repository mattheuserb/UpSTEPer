# Test data

## Rules

- Only commit files whose licence allows redistribution; record source and licence here and in
  `examples/README.md`.
- Never commit modified versions of No-Derivatives files. Tests write outputs to temp folders.
- Prefer small files that each exercise one thing.

## Files

### `examples/ESKV 12 RAL 7035 10066410.stp`

| | |
|---|---|
| Part | Cable gland ESKV 12, RAL 7035 |
| Source | CADENAS PARTsolutions, exported with STEP Tools ST-Developer v20 |
| Licence | CC BY-ND 4.0 (stated in the file header) |
| Schema | AP214 (`AUTOMOTIVE_DESIGN`) |
| Topology | 1 `MANIFOLD_SOLID_BREP`, 1 closed shell, 109 faces, 251 edges, 173 vertices |
| Surfaces | 54 `PLANE`, 38 `CYLINDRICAL_SURFACE`, 13 `CONICAL_SURFACE`, 3 `TOROIDAL_SURFACE`, 1 degenerate torus |
| Curves | 132 `LINE`, 101 `CIRCLE`, 18 short cubic `B_SPLINE_CURVE_WITH_KNOTS` (intersection curves) |
| Colour | one `STYLED_ITEM` on the solid: `COLOUR_RGB(0.76, 0.79, 0.77)` |

**Quality assessment:** this is a *clean*, fully analytic model. Circles are exact `CIRCLE`
entities and cylinders are exact `CYLINDRICAL_SURFACE`s. If round features look polygonal in a
viewer, that is the viewer's display tessellation, not a defect of the file — lower the angular
deflection (`TessellationOptions.Fine`).

Good for: loading, statistics, body colour, tessellation, DXF export of circles/arcs.
Not useful for: repair (nothing to repair).

### Regenerating the generated files

Windows, with vcpkg at `C:\vcpkg` (`-Tools` builds the generators, see `scripts/build-native.ps1`):

```powershell
./scripts/build-native.ps1 -VcpkgRoot C:\vcpkg -Tools
$env:PATH = "$PWD\artifacts\native\win-x64;$env:PATH"
native\build\win-x64\upsteper_make_test_assembly.exe examples\generated\test-assembly.stp
native\build\win-x64\upsteper_make_damaged_parts.exe examples\generated\damaged-parts.stp
```

Other platforms: `cmake --preset <preset> -DUPS_BUILD_TOOLS=ON` and build the
`upsteper_make_*` targets.

## Large local files (not in the repository)

Too big for Git (and not ours to redistribute); download them into `examples/local/`, which is
ignored. Nothing in the test suite requires them; they are for performance measurements.

### `examples/local/Scania-Engine-V8-XT-Turbo.step`

- Source: STEP Tools large-assembly samples,
  <https://www.steptools.com/docs/stpfiles/bigassy/Scania-Engine-V8-XT-Turbo.step> (374 MB,
  AP203). Originally "Scania V8 XT Turbo Engine" by Ivo Jardim on GrabCAD, Autodesk Inventor.
- Licence: none stated; GrabCAD library terms apply. Use locally only, never commit.
- Download: `curl -L -o examples/local/Scania-Engine-V8-XT-Turbo.step <url above>`
- Content: 1,295 solids, 71,873 faces, 184,576 edges, 2,593 tree nodes; 2.47 m diagonal.

Measurements (2026-10-09, Windows 11, 11th Gen Intel(R) Core(TM) i9-11900H @ 2.50GHz, 32 GB RAM, OCCT 8.0.1, Release build):

| Step | Time | Result |
|---|---|---|
| Load (read 13 s + transfer 46 s) | 59 s | 0.5 GB working set |
| Bounds from edges | 0.35 s | 2,474 mm (`AddOptimal`: same, 141 s; `Add` on faces: 11,825 mm) |
| Coarse / Normal / Fine | 7.6 / 8.4 / 11.9 s | 1.3 / 2.7 / 6.9 million triangles |
| Normal without minimum size | 12.9 s | 12.1 million triangles (old Fine: 100 million, 140 s, 7.5 GB) |
| BVH build (7.8 million triangles) | 1.8 s | picking 21 µs (brute force 82 ms) |
| `check` (159 part definitions) | 91 s incl. load | 36 parts with findings: 1,121 canonical spline faces, 210 mergeable faces, 46 small edges, 22 invalid sub-shapes, 1 failed sub-check |
| `repair` (tier 1: fix, sew, merge) | 178 s incl. load and save | 128 parts changed, 155 faces merged, invalid 22 -> 21; merging discarded as worse in 8 parts, 1 failed step |
| `repair` (all steps incl. canonical) | 280 s incl. load and save | additionally 266 spline faces -> exact surfaces (max. deviation 0.0495 mm at 0.05 mm tolerance); a step discarded as worse in 10 parts |
